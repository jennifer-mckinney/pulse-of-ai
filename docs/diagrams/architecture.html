Component Reference
# Component Layer Description
① collectors/reddit.js Ingest Reddit Pushshift API collector; falls back to mock generator when credentials absent
① collectors/arxiv.js Ingest arXiv query API — no auth required; collects AI-domain papers
① collectors/rss.js Ingest rss-parser feeds for news, policy, and blog sources across 7 categories
① collectors/scraper.js Ingest Playwright headless scraper for P2 sources (LinkedIn, Threads, etc.)
② pipeline/ingest.js Ingest Orchestrator: collect → strip PII → SHA-256 dedup → store raw_posts. BullMQ worker, 2–3 min staggered refresh
④ pipeline/sentiment.js Pipeline AFINN lexicon v5.0.2. Writes sentiment_results + decision_audit_log. Methodology version 1.0.0
④ pipeline/relevance.js Pipeline 15-keyword AI-domain hybrid scorer. Score = matched/total capped at 1.0
④ pipeline/discourse.js Pipeline Deliberative Quality Index (DQI) + semantic improvements per §18 of TECHNICAL_SPEC.md
⑤ pipeline/embeddings.js Pipeline Sends content to Python Infinity service; stores VECTOR(384) in post_embeddings. Model: all-MiniLM-L6-v2
④ pipeline/correlation.js Pipeline Cross-platform verb-noun pseudonymous IDs (e.g. running-tiger). Assigns ID only at ≥0.85 confidence
③ raw_posts Storage Immutable source records. content_hash prevents duplicates. raw_payload JSONB strips PII on ingest
③ decision_audit_log Storage Every inference written here: model name, version, input_hash, output JSONB, confidence. Explainability backbone
③ methodology_versions Storage Versioned algorithm configs with plain-English justification field for regulators and journalists
③ post_embeddings Storage 384-dim vectors. IVFFlat cosine index (lists=100) for ANN search. Powers semantic similarity queries
③ bias_assessments Storage Per-job bias metrics. is_violation=TRUE triggers alert_events. Thresholds documented in methodology_versions
③ data_retention_log Governance GDPR lifecycle tracking: collected → anonymized → deleted. Legal basis field per GDPR Article
③ compaction_log Governance Monthly Tier 1 → Tier 2 compaction audit trail. 3-tier retention: 90-day detail → monthly rollups → permanent
⑥ GET /api/posts/aggregated-by-location API Sentiment totals + per-source breakdown by city. Powers Mapbox 3D bar chart markers
⑥ GET /api/audit/:post_id API Full decision trail for any post: sentiment, relevance, discourse scores + model + methodology justification
⑥ GET /api/config API Serves MAPBOX_ACCESS_TOKEN to browser at runtime. Token lives in .env only, never in client JS source
⑥ GET /api/health API DB connectivity + last job status + active bias alert_events. Dashboard health indicator source
⑦ public/js/map.js Frontend Mapbox GL JS globe projection. 3D fill-extrusion sentiment bars (green/yellow/red) + stacked source column. Rich hover tooltips. All gestures custom-implemented
⑦ public/js/main.js Frontend Health status indicator and manual refresh button wired to /api/health
