Component Reference
# Component Layer Description
② queues/index.js Ingest BullMQ queues: collect.reddit / collect.rss / collect.arxiv / collect.scraper plus ingest, embed, correlate. Collect processors land in a later phase (planned)
② workers/collector.scheduler.js Ingest Per-source BullMQ v5 job schedulers: staggered startDate spreads active sources across the collect window (default 2 min); stale schedulers cleaned up. Wiring into workers/start.js is planned
② pipeline/ingest.js Ingest Orchestrator: normalise → strip PII → SHA-256 dedup → store raw_posts, then sentiment/relevance/discourse scoring
④ pipeline/sentiment.js Pipeline AFINN lexicon via 'sentiment' npm ^5.0.2. Writes sentiment_results + decision_audit_log. Methodology version 1.0.0
④ pipeline/relevance.js Pipeline 20-keyword AI-domain lexicon scorer. Score = matched/20, capped at 1.0
④ pipeline/discourse.js Pipeline Deliberative Quality Index (DQI) + semantic improvements per §18 of TECHNICAL_SPEC.md
⑤ pipeline/embeddings.js Pipeline Sends content to the Python FastAPI embeddings service (sentence-transformers); stores VECTOR(384) in post_embeddings. Model: all-MiniLM-L6-v2
④ pipeline/correlation.js Pipeline Cross-platform adjective-animal pseudonymous IDs (e.g. balanced-impala). Assigns ID only at ≥0.85 confidence
③ raw_posts Storage Immutable source records. content_hash prevents duplicates. raw_payload JSONB strips PII on ingest
③ decision_audit_log Storage Every inference written here: model name, version, input_hash, output JSONB, confidence. Explainability backbone
③ methodology_versions Storage Versioned algorithm configs with plain-English justification field for regulators and journalists
③ post_embeddings Storage 384-dim vectors. HNSW cosine index (m=16, ef_construction=400) for ANN search. Powers semantic similarity queries
③ bias_assessments Storage Per-job bias metrics. is_violation=TRUE triggers alert_events. Thresholds documented in methodology_versions
③ data_retention_log Governance GDPR lifecycle tracking: collected → anonymized → deleted. Legal basis field per GDPR Article
③ compaction_log Governance Monthly Tier 1 → Tier 2 compaction audit trail. 3-tier retention: 90-day detail → monthly rollups → permanent
⑥ GET /api/posts/aggregated-by-location API Sentiment totals + per-source breakdown by city. Powers the globe sentiment bars (legacy Mapbox today; globe.gl story planned)
⑥ GET /api/audit/:post_id API Full decision trail for any post: sentiment, relevance, discourse scores + model + methodology justification. Input fingerprint exposed as HMAC-SHA256 keyed by AUDIT_HASH_KEY env (omitted when unset)
⑥ GET /api/config API Serves MAPBOX_ACCESS_TOKEN to browser at runtime. Token lives in .env only, never in client JS source
⑥ GET /api/health API DB connectivity + last job status + active bias alert_events. Dashboard health indicator source
⑥ GET /api/themes API Keyword themes for scroll-story chapters: volume + sentiment split + modal source category per matched keyword. Max 12 themes, min 3 posts each
⑥ GET /api/sources · GET /api/sources/timeseries API Source registry listing, plus hourly zero-filled post counts by category (1–48 h window, default 12 h)
⑥ POST /api/query API Post search with platform, city-level location, and from/to date filters; limit capped at 100
⑥ GET /api/bias/latest API Bias monitor: reads the latest completed bias job's assessments (parity metrics + violation flags) from bias_assessments (src/routes/bias.js)
⑥ GET /api/methodology API Model registry: active methodology versions per pipeline component from methodology_versions (src/routes/methodology.js)
⑥ POST /api/refresh API Rate-limited job trigger (1 request/min/IP); collectors land in Phase E (src/routes/refresh.js)
⑦ public/js/config/ Frontend story.config.js, design.config.js, api.config.js — data-only configuration for the scroll story (delivered)
⑦ public/js/utils.js · data.js · insights.js · chapters.js Frontend utils.js, data.js, insights.js, chapters.js — pure DOM-free modules, jest-tested (delivered)
⑦ public/vendor/ Frontend Vendored assets, no CDN (FR-25): globe.gl, scrollama, IBM Plex Mono + Space Grotesk fonts, world-atlas land-110m GeoJSON (delivered)
⑦ globe.js · story.js · ui.js Frontend Browser layer of the storytelling frontend (C2–C4, planned); page shell C1 in progress
⑦ public/js/map.js Frontend Legacy Mapbox GL JS globe projection with 3D fill-extrusion sentiment bars. Removal planned (C5) once the globe.gl story ships
⑦ public/js/main.js Frontend Health status indicator wired to /api/health; manual refresh button reloads the page
