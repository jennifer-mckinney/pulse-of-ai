The three trust boundaries (browser to web, worker to the internet, containers to the host) and the control that guards each crossing: CSP, CORS scope, the refresh CSRF guard, the SSRF guard, named gate approval, secret scrubbing and PII redaction.

  subgraph WEBB["Boundary 1 · web (public surface)"]
    direction TB
    C1["every response: CSP default-src 'self', script-src 'self',<br/>style-src 'self', object-src 'none', base-uri 'self',<br/>frame-ancestors 'none';<br/>X-Content-Type-Options nosniff, X-Frame-Options DENY,<br/>Referrer-Policy no-referrer"]:::done
    C2["CORS only on the read-only router;<br/>POST /api/refresh mounted first, without CORS,<br/>OPTIONS answered 403"]:::done
    C3["refresh CSRF guard: Sec-Fetch-Site must be same-origin or none;<br/>if the header is absent, Origin (else Referer) host = Host;<br/>anything else 403;<br/>X-Refresh-Token checked whenever REFRESH_TOKEN is set;<br/>no token set: 403 when bound beyond loopback,<br/>on a wildcard bind outside the compose container,<br/>or via a proxy (Forwarded, X-Forwarded-For / -Host, X-Real-IP);<br/>409 in flight, 60 s global debounce"]:::done
    C4["input validation: UUID post ids, integer hours,<br/>canonical categories, dates, limit ≤ 100;<br/>malformed JSON → 400 JSON (jsonErrorHandler);<br/>no stack, path or upstream text in any error;<br/>500s return a generic message only"]:::done
    C5["audit input_hash served as HMAC(AUDIT_HASH_KEY),<br/>omitted without a key; /api/sources serves error_kind<br/>and http_status, never error text or env values"]:::done
    C6["frontend: textContent only, no innerHTML;<br/>all assets self-hosted, no CDN"]:::done
    C7["log scrubbing: every route handler error (log-error.js)<br/>and PostgreSQL pool error passes scrub;<br/>control characters escaped, one line per error"]:::done
  end

  subgraph WORKB["Boundary 2 · worker to the internet"]
    direction TB
    S1["SSRF guard on every hop: https only, public hosts,<br/>route allowedHosts, DNS answers checked and pinned,<br/>redirects checked hop by hop (max 4)"]:::done
    S2["credentials never cross origins: a credentialed<br/>request is refused a cross-origin redirect"]:::done
    S3["response caps (5 MB, robots 500 KiB, bulk 50 MB),<br/>decompression counted, DTD entities refused,<br/>linear-time text processing"]:::done
    S4["politeness: contact User-Agent, robots.txt,<br/>per-host spacing; 401/403/451/challenge never retried,<br/>source enters the refused state"]:::done
    S5["secret scrubbing: every stored or logged error passes<br/>redactUrl + scrub (env secrets raw and URL-encoded)"]:::done
    S7["named approval: a gated route (key, approval, licence<br/>or permission) opens only with a valid GATE_APPROVED_BY<br/>(Name YYYY-MM-DD); gate changes recorded with approved_by<br/>in append-only source_gate_events"]:::done
    S6["PII: allowlisted payload, PII_FIELDS removed,<br/>in-text redaction (ingest@1.8.0), city-level location,<br/>identity-bearing ids stored as keyed fingerprints"]:::done
  end
