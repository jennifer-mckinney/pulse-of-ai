  [*] --> running : cron cycle created at the first new post of a window (triggered_by cron)
  [*] --> running : refresh (api), standup, manual or demo job created

  running --> closing : cron only, window + 60 s grace over and inflight_runs 0, or hard cap reached
  closing --> completed : posts counted from decision_audit_log, bias checks once when posts exist
  closing --> failed : close error (scrubbed)
  closing --> closing : cron only, re-claimed when its closer died (still closing 2 x the hard cap after started_at)

  running --> completed : single job run finished with no reserved scoring slot held, posts counted from decision_audit_log, bias checks when any
  running --> awaiting : single job still holding reserved scoring slots (a refresh's queued ingest jobs, or scoring retries)
  awaiting --> closing : retries done (inflight_runs 0) or hard cap reached
  running --> failed : single job only — run threw (a cron cycle stays running), enqueue failed (refresh 503), or no progress (last_progress_at, else started_at) for REFRESH_STALE_MINUTES (api) or STALE_JOB_MINUTES (30), marked by the refresh route or the stale-job sweeper (maintenance job, every 5 min)

  completed --> [*]
  failed --> [*]
